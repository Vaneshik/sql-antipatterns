            Основания и область проверки
            
    Символьный анализ учитывает кратность строк, NULL, типы и PRIMARY KEY из схемы выше.
              Поддерживаются чистые выражения с определённым результатом для всех допустимых входов.
              На проверку свойств каждого плана отведена 1 секунда.
    
            
    Доказанное свойство относится к указанному узлу и его контексту.
              «После» применяет доступные преобразования исходного SQL и заново строит дерево.
              Для вложенных конструкций часть рекомендаций требует ручного изменения SQL.
              Время выполнения запроса в СУБД измеряется отдельно.
